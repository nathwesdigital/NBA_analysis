Decision summary

Current-state member recommendation

Goal

Based on everything we know right now, what should we do next for this customer to maximise value for both the customer and the business? The model returns one current, actionable recommendation rather than a list of competing messages.

Audience And Status Paths

Only current trial and active paid members are assessed. Paid members in current grace route to payment recovery; trial and active paid members progress through engagement actions; account-only, cancelled, lapsed and other non-current states are excluded; unclassified in-scope members return NULL for data-quality review.

How The Decision Is Made

Urgency wins first: payment recovery, unredeemed rewards, then incomplete challenges. The remaining path checks Flybuys, division links, mobile app, push opt-in, and finally annual-plan eligibility for paid monthly high-engagement members. na_complete means every modelled action is complete or inapplicable.

API/MCP and CSV examples

This API/MCP example uses next_best_action as an object-array attribute containing the action name, conversion event, and timing. This example intentionally omits _update_existing_only.

{
  "attributes": [
    {
      "external_id": "{{${user_id}}}",
      "next_best_action": [
        {
          "name": "link_flybuys",
          "conversion_event": "flybuys_linked",
          "updated_at": {
            "$time": "2026-08-04T04:37:33Z"
          },
          "hold_until": {
            "$time": "2026-08-17T23:00:00Z"
          }
        }
      ]
    }
  ]
}

CSV delivery cannot write this nested object-array structure; use a separate flat attribute or an API/MCP or Cloud Data Ingestion path for this model. Without _update_existing_only, an unknown external_id can create a Braze profile, so validate the delta audience before delivery.
